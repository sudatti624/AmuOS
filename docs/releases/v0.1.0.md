AmuOSの最初のプレリリースです。まだ開発途中で、できることは多くありませんが、Linuxに入れて、画面からユーザーと権限の管理を試していただけるところまで来ました。触ってみて気づいたことがあれば、Issueで教えていただけると、とても助かります。

> [!WARNING]
> 開発途中のソフトウェアです。データのバックアップ・復元や更新の仕組みはまだなく、APIやデータ形式も予告なく変わることがあります。本番環境やインターネットに公開された環境での利用はお控えください。

## できること

- 初回設定（ローカルで発行する10分・1回限りのトークン）によるオーナーの作成
- ログイン・ログアウト、パスワード変更、期限付きの招待によるユーザーの追加
- Owner / Admin / Operator / Viewer のロールを、全ホストまたはホスト単位で、ユーザーへ直接またはグループ経由で割り当て。変更はログイン中のセッションにも反映されます
- オーナーの追加・解除・移譲（パスワードの再確認つき）
- 監査ログの閲覧と、保持期間の設定・期限切れログの自動削除
- ホストの登録枠（ID）の確保と一覧
- 日本語のWeb画面（ダーク/ライトテーマ）

## まだできないこと

- Agentによるホスト情報の取得、監視とグラフ、タスク
- データのバックアップと復元
- systemdでの常駐、再インストールなしの更新の仕組み
- Linux amd64 以外向けの配布

## 導入

`amuos_0.1.0_linux_amd64.tar.gz` と `SHA256SUMS` をダウンロードし、同梱の `INSTALL.md` の手順に沿って導入してください。ソースからのビルド手順はREADMEにあります。

## 確認した環境

- GitHub Actions の Ubuntu 24.04 と、Debian 13 のコンテナで、この配布ファイルを手順どおりに導入し、初回設定・ログイン・ホスト登録枠の作成・再起動後のデータ保持を自動テストで確認しました。
- Ubuntu 24.04 上で、画面の主要な操作（初回設定、招待、権限による表示の制限、APIを直接呼んだときの拒否、権限変更の反映、パスワード変更など）をブラウザのE2Eテストで確認しました。
- 実機の Ubuntu Server や Debian での長時間の運用、systemdでの常駐は、まだ確認していません。
