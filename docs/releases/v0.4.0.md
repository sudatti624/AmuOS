AmuOSのv0.4.0プレリリースです。この版では、Windowsへの対応を加えました。Control PlaneとAgentをWindowsサービスとして動かし、Windowsホストの情報や監視値を、これまでのLinuxホストと同じ画面で確認できます。WSLや仮想マシンを使わずに試せるようになりました。まだ開発途中ですが、試していただいて気づいたことがあれば、Issueで教えていただけるととても助かります。

> [!WARNING]
> 開発途中のソフトウェアです。実機での長時間の運用や、独立した環境での復元の総合検証はまだ済んでいません。APIやデータ形式も予告なく変わることがあります。本番環境やインターネットに公開された環境での利用はお控えください。

## 新しくできること

- **Windowsでの常駐**：Control PlaneとAgentを、それぞれWindowsサービスとして登録できます。専用の仮想アカウントで動き、管理者権限やアカウントのパスワードは与えません。鍵・データベース・Agentの記録はNTFSのアクセス制御で保護し、サービスが書き込める場所は自身の状態ディレクトリに絞ります。
- **Windowsホストの監視**：CPU・物理メモリ・システムドライブの使用率、固定ドライブの容量、ディスクI/O、物理ネットワークの転送量、ホスト名・カーネル版・CPUモデル・メモリ容量・ネットワークインターフェースを取得します。履歴グラフや「今すぐ収集」、タスクの結果確認と再実行は、Linuxと同じ画面から使えます。取得できない値は0で代用しません。
- **Windowsでの導入・更新・切り戻し**：配布物にPowerShellの管理スクリプトと手順を同梱しました。Control Planeの更新では、サービスを停止し、新しい本体でデータベースの互換性を確認してから、旧本体で暗号化バックアップを取ります。問題があれば、保存した旧本体と更新前のデータベースの組で戻せます。アンインストールではサービスを削除し、状態・鍵・バックアップは残します。
- **Windows用の配布ファイル**：Linux amd64用のtar.gzに加え、Windows amd64用のZIPを用意しました。両方のファイルのSHA-256を `SHA256SUMS` にまとめ、依存ソフトウェアのライセンスもそれぞれに同梱しています。
- Windowsで取得できないsystemdの状態は、画面に「対応していません」と表示します。サービスの起動・停止やエラーはWindowsのApplicationイベントログで確認できます。

## はじめかた

Windowsでは `amuos_0.4.0_windows_amd64.zip` と `SHA256SUMS` をダウンロードし、ハッシュを照合してから展開してください。同梱の `INSTALL-WINDOWS.md` に、Control Planeの導入、初回設定、Agentの登録、更新と切り戻しの手順があります。サービスの登録には、管理者として起動した64ビットPowerShellが必要です。導入スクリプトはファイアウォールの設定を変更しません。

Linuxでは、これまでどおり `amuos_0.4.0_linux_amd64.tar.gz` と `SHA256SUMS` を使い、同梱の `INSTALL.md` に従って導入できます。

## v0.3.0 からの更新

データベースの形式はスキーマv13のままで、この版で新しい移行はありません。Linuxでは、同梱の `INSTALL.md` の「更新」の手順に従い、停止・更新前バックアップ・本体の差し替え・再起動を行ってください。Windows用のサービス導入手順は、この版からの提供です。

Control Planeをバックアップから復元した場合は、従来どおりログイン中のセッションとAgentの資格情報が無効になります。各Agentを新しいコードで登録し直してください。切り戻しで復元する場合も同じです。

## まだできないこと

- WindowsでのLoad、Linuxと同じ意味でのSwap、起動時刻の取得。64論理CPUを超えるWindowsホストのCPU使用率も、今は取得できません
- Windowsサービスの一覧・開始・停止の管理画面からの操作。systemdの状態取得はLinuxのみです
- Windowsのディスク監視カウンターが無効・利用不能な環境でのディスクI/O取得
- 自動バックアップのスケジュール、Webからの復元
- 実機での24時間連続運転など、初期リリース全体の総合検証

## 確認した環境

- Windows 11 amd64の実機で、両サービスの導入、専用アカウント・NTFSのアクセス制御、Agentの登録、実測の監視値と収集タスク、停止と再起動、別の版への更新、旧本体と更新前データベースを使った切り戻し、アンインストールを確認しました。一般ユーザーからTLS秘密鍵と両サービスの状態ファイルを読めないことも確認しています。
- Windowsで、Go全テスト、Webの検査・テスト・ビルドと、実Agentを使うものを含むブラウザーE2E全5件が成功しています。Linux向けの静的検査とクロスビルドも確認しました。
- 配布前のGitHub Actionsでは、Windowsのサービス試験とブラウザーE2E、Linuxのテスト・導入・復元試験を実行し、すべての成功を公開の条件にしています。
- Windows Server 2025での実行、実機での長時間運転、時計の大きなずれや電源断を伴う確認は、まだ行っていません。
